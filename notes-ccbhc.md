# CCBHC Implementation Notes

*By [Jon Villasurda Jr., MPH](/about/)*

These notes summarize public implementation considerations for Certified Community Behavioral Health Clinics.

## Core implementation questions

- Which certification requirements must become operational workflows?
- How will crisis services, care coordination, referrals, and follow-up work day to day?
- Which measures help program leaders manage access, quality, utilization, and finance?
- How will policy design and payment assumptions be tested after launch?

## Working principles

- Define governance and accountability before implementation expands.
- Keep measurement useful for operations, not only reporting.
- Connect clinical workflows, payment design, and state oversight.
- Revisit assumptions after early utilization and access patterns are visible.
