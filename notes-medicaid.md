# Medicaid Delivery Design Notes

Medicaid delivery design has to connect policy intent with operational feasibility.

## Design considerations

- Start with the beneficiary experience and the implementation roles that support it.
- Align financing, accountability, reporting, and performance measures.
- Distinguish first-phase operating requirements from longer-term transformation goals.
- Design evaluation questions early enough to shape data collection.

## Implementation checks

- Confirm who owns each workflow across state, plan, provider, and vendor participants.
- Define the small set of measures leaders need repeatedly.
- Make integration requirements explicit where behavioral and physical health systems intersect.
- Plan for adjustment after early program evidence is available.
