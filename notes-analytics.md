# Public Sector Analytics Notes

Public sector analytics should make decisions clearer without hiding operational constraints.

## Useful analytic outputs

- A baseline view of population, services, and variation
- A measure dictionary with stable definitions
- A recurring dashboard for operating questions
- A focused evaluation plan for outcome questions

## Working principles

- Start from the decision to be made.
- Make limitations visible.
- Separate descriptive reporting from causal claims.
- Keep definitions stable enough to compare over time.
