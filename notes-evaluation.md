# Program Evaluation Notes

Program evaluation is most useful when it is designed for decisions, not only retrospective reporting.

## Evaluation framing

- State the program problem and the decisions the evaluation should inform.
- Separate implementation monitoring from outcome evaluation.
- Confirm data availability before finalizing metrics.
- Include measures for access, utilization, quality, finance, and variation where relevant.

## Practical outputs

- A baseline and target population definition
- A measure dictionary
- A recurring management view
- A deeper evaluation plan for outcomes and tradeoffs
